# Agent instructions

Every script here is a published interface. `.pre-commit-hooks.yaml` names each one as an `entry:`, and consumer repositories reach them through `repo: https://github.com/tbhb-dev/devtools` plus a `rev:`, which resolves the entry path against this repository's root. A path in this directory belongs to the package's public surface the same way an exported function does. Rename one and every consumer breaks at their next `rev:` bump, in their commit hook rather than here. Treat a change to a filename or a calling convention as a breaking change that needs a major version and a coordinated update, not as tidying. The directory holds these five because they arrived with the fold-in of `tbhb/pre-commit-hooks`, whose hook IDs this repository preserves unchanged so a consumer edits only the `repo:` and `rev:` lines.

`commit-trailers.sh`, `commitlint.sh`, `vale-commit-msg.sh`, and `cspell-commit-msg.sh` each take the commit-message buffer path as their single argument and run on the `commit-msg` stage. `clear-commit-agentmsg.sh` runs on `post-commit` instead and takes no arguments. A consumer installing it needs that stage installed too, through `prek install -t post-commit`. The first two of those, along with `clear-commit-agentmsg.sh`, depend only on bash, git, grep, and sed, which is what lets a consumer install them with no toolchain. `vale-commit-msg.sh` and `cspell-commit-msg.sh` also need the consumer to have vale or cspell installed along with a configuration defining the commit-message scope, so neither may grow a dependency beyond that pair.

Tests live in [`../tests/scripts/`](../tests/scripts/), one bats suite per script, and `mise run test-hooks` runs them. `commit-trailers.sh`, `commitlint.sh`, and `clear-commit-agentmsg.sh` have suites. `vale-commit-msg.sh` and `cspell-commit-msg.sh` don't, because both delegate to an external linter whose behavior isn't this repository's to assert. A suite reaches its subject through `${BATS_TEST_DIRNAME}/../../scripts/`, so moving either directory means fixing that path.

`mise run lint-script-hygiene` covers `scripts/*.sh` alongside the skill scripts, so the hardening block and the `gitr` wrapper rules apply here too. Read the repository-root [`AGENTS.md`](../AGENTS.md) for those conventions, and [`../tools/AGENTS.md`](../tools/AGENTS.md) for the internal tooling this directory is deliberately not part of.
